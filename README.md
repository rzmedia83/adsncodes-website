# Ads n' Codes website (adsncodes.com)

Custom static website. Pages are generated by Python from the files in `site2/`, then uploaded to Hostinger (`public_html`).

## Build
```
cd site2 && python3 build.py     # renders all pages
cd .. && python3 mkprod.py       # copies everything into prod/ with cache-busting hashes
```
Upload the contents of `prod/` to Hostinger `public_html`. Do not use Hostinger Git auto-deploy: the demo subdomains (medicare, realestate, grillhouse, inventa, backtoroots) live inside `public_html` and a full deploy would remove them.

## Layout
- `site2/build.py` page templates, schema, sitemap, navigation
- `site2/*_data.py` content for services, cities, SEO pages, articles, case studies
- `site2/ar_build.py` Arabic pages (hidden until reviewed, `AR_LIVE = False`)
- `site2/src/` hand written pages (home, contact, free audit form, calculator)
- `site2/assets/` CSS, JS, images, video, fonts
- `server/` files that live only on the server: `.htaccess` (redirects, headers, caching) and `audit.php` (audit form handler)
- `tools/` upload, QA and SEO audit scripts. Upload keys are never stored here.
