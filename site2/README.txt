Ads n' Codes website (adsncodes.com) - source code

This is a custom static website, not WordPress. Pages are generated by Python
from the files in this folder, then uploaded to Hostinger (public_html).

Build:
  cd site2 && python3 build.py      (writes the HTML pages next to build.py)
  cd .. && python3 mkprod.py        (copies everything into prod/ with cache hashes)
Upload the contents of prod/ to Hostinger public_html (File Manager or FTP).

Where things live:
  build.py            page templates, schema, sitemap, navigation
  services_data.py    service pages (titles, copy, FAQs)
  city_services.py    Abu Dhabi and Sharjah service pages
  locations_data.py   emirate pages
  seo_data.py         SEO pages and title overrides
  articles_data.py    Insights articles
  case_data.py        case studies
  ar_build.py         Arabic pages (hidden until reviewed, AR_LIVE=False)
  src/                hand written pages (home, contact, audit form, calculator...)
  assets/             CSS, JS, images, video, fonts
  llms.txt            summary for AI search tools
  lastmod.json        real last changed date per page, used by the sitemap
Tools: mkprod.py (build output), up.sh (upload; needs a fresh Hostinger upload key), seoaudit.py, qa.js
